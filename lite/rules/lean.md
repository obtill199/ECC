# Tilly lean rules

- Scope: do the asked slice only.
- Models: Sonnet for work, Haiku for grunt. No Opus unless named.
- Secrets: never commit keys or .env values.
- Facts: do not invent.
- HTML sites: mobile-first, obvious phone/CTA, working links, Wichita-plain language.
- TS apps: smallest change that fixes the bug; tests only for silent regressions.
- Sports: evidence and uncertainty; no lock/guarantee language unless the user is using a separate picks system.
- Jobs: truthful tailoring only.
- Furniture: profit and construction first, taste second.
- Sessions: new chat after the task ships.
