# Usage guard

- One task per session.
- Plan then implement then review. Do not mix all three into a ramble.
- Prefer editing existing files over new abstractions.
- If you have reread the same file twice, stop exploring and decide.
- If the user switched projects, tell them to start a new chat.
- Never enable hooks or extra MCP to "be thorough."
